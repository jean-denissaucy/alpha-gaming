# Script oral - 2 minutes (Jury)

Bonjour, je vous presente mon projet Actu Gaming.

C'est une application web dynamique full-stack avec React pour le frontend, Node.js/Express pour le backend et MySQL pour la base de donnees relationnelle.

Le besoin etait de proposer une plateforme d'actualites gaming et esport avec une partie publique et une partie membre securisee.

Cote frontend, j'ai realise des interfaces statiques structurees, puis des interfaces dynamiques avec React:
- navigation par routes,
- formulaires login/register,
- affichage conditionnel selon l'etat connecte,
- dashboard protege.

Cote backend, j'ai mis en place une API REST avec separation routes/controleurs/modeles, une authentification JWT et un middleware de protection.

Pour la base de donnees, j'ai cree un schema relationnel MySQL avec cles primaires, cles etrangeres, contraintes d'unicite et index.

J'ai aussi documente l'installation, la configuration d'environnement et le deploiement production, avec des fichiers .env.example pour le front et le back.

Demonstration rapide:
1. Lancement du projet
2. Consultation de la page d'accueil
3. Inscription puis connexion
4. Acces au dashboard protege
5. Verification d'un endpoint API

Conclusion: le projet couvre les competences professionnelles demandees sur le front-end, le back-end, la base relationnelle et la documentation de deploiement.

Mes prochaines ameliorations sont l'ajout de tests automatises et le renforcement de la validation des donnees serveur.
